# 流萤动态博客 · 上线自检清单

按顺序逐项确认，全部通过即可对外提供服务。

## 一、部署与环境

- [ ] Node.js ≥ 20.9、pnpm 10.x、MySQL 8 均已安装且版本符合要求
- [ ] 已创建独立数据库账号（非 root），并只授予 `firefly_blog.*` 权限
- [ ] `pnpm install --frozen-lockfile` 无报错
- [ ] `pnpm db:generate`、`pnpm db:deploy`、`pnpm db:seed` 均执行成功
- [ ] `pnpm build` 通过，`next start`（systemd / PM2）启动后 `pm2 status` 或 `systemctl status` 正常
- [ ] 进程守护已配置开机自启

## 二、配置与安全

- [ ] `.env` 为 UTF-8 编码，权限受限（Linux `chmod 600`）
- [ ] `AUTH_SECRET`、`CRON_SECRET` 已替换为随机值，且与开发环境不同
- [ ] `ADMIN_PASSWORD` 已改为强密码，首次登录后建议再次在后台修改
- [ ] `AUTH_URL`、`SITE_URL` 均为对外 https 域名
- [ ] `UPLOAD_DIR` 指向持久化目录且服务账号可写
- [ ] 仅开放 80 / 443 端口，3000 未暴露到公网
- [ ] HTTPS 证书签发成功，`certbot` 自动续期定时器存在

## 三、前台功能

- [ ] 首页卡片流按置顶优先、发布时间倒序展示，分页可正常翻页
- [ ] 文章详情页正文渲染正常（中文、emoji、代码块高亮、表格均正确）
- [ ] 正文中的行内脚本 / 危险标签已被过滤（在编辑器写入 `<script>alert(1)</script>` 验证不执行）
- [ ] 目录（TOC）随标题生成，锚点可跳转
- [ ] 阅读数在刷新详情页后自增
- [ ] 分类页、标签页、标签云、归档页、搜索页均可正常使用
- [ ] 搜索可命中标题与正文内容
- [ ] 自定义页面（如「关于」）可通过 `/page/slug` 访问
- [ ] 明暗主题切换正常，移动端布局不溢出

## 四、后台功能

- [ ] 未登录访问 `/admin` 会跳转到 `/admin/login`
- [ ] 连续 5 次输入错误密码后账号被锁定 10 分钟
- [ ] 新建文章 → 选择「定时发布」并设置 2 分钟后的时间 → 到点后前台可见
- [ ] 草稿与私密文章在前台列表、详情、RSS、站点地图中均不出现
- [ ] 删除非空分类时被要求选择文章去向，迁移后文章分类正确
- [ ] 标签合并后文章关联与计数正确
- [ ] 编辑器内插入图片、上传封面正常，媒体库可复制地址与删除
- [ ] 上传非图片文件或超过 10MB 的文件会被拒绝并提示
- [ ] 站点设置（名称、导航、社交、备案、SEO、评论预留）保存后前台生效
- [ ] 修改密码后旧会话失效，需要重新登录

## 五、SEO 与订阅

- [ ] 各页面 `<title>`、描述、关键词输出正确
- [ ] `/sitemap.xml` 包含文章、分类、标签与页面，且不含草稿/私密内容
- [ ] `/robots.txt` 屏蔽 `/admin` 与 `/api`
- [ ] `/rss.xml` 可被阅读器正常订阅，文章链接为绝对地址
- [ ] 文章页包含 JSON-LD 结构化数据

## 六、定时任务与备份

- [ ] 定时发布兜底任务已注册，手动执行返回 `{"ok":true,...}`
- [ ] 数据库备份任务已注册，`backups` 目录出现新的备份文件
- [ ] 上传目录备份已按计划打包
- [ ] 已完成一次恢复演练（恢复到测试库并启动服务验证）

## 七、收尾

- [ ] 首页与文章页在主流浏览器（Chrome / Edge / Firefox / Safari）显示一致
